# Add a GitHub Team to a Repository

Add a GitHub Team to a Repository

## Usage

``` r
add_team_to_repo(repository, team, org = "openscapes")
```

## Arguments

- repository:

  The name of the GitHub repository.

- team:

  The name of the team.

- org:

  The GitHub organization that owns the team and the repository.
